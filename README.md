# IndieZone 🎮

Plataforma web para distribuição digital de jogos independentes brasileiros.

## Sobre o projeto

O IndieZone é uma plataforma web desenvolvida como Trabalho de Conclusão de Curso em Análise e Desenvolvimento de Sistemas.

A proposta é aproximar desenvolvedores independentes e jogadores por meio de uma plataforma que reúne publicação, descoberta, aquisição, avaliação e interação com jogos.

## Funcionalidades

- Cadastro e autenticação de usuários
- Cadastro de desenvolvedores
- Publicação e gerenciamento de jogos
- Catálogo e busca de jogos
- Página de detalhes dos jogos
- Compra e aquisição de jogos
- Biblioteca do usuário
- Lista de desejos
- Avaliações e comentários
- Sistema de comunidade
- Seguimento de desenvolvedores
- Atualização de jogos
- Moderação e denúncias
- Painel administrativo
